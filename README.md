## What It Does

A **browser-based tool that converts Markdown into beautiful PDF documents**. Type or paste Markdown on the left, see a formatted preview on the right, then download as PDF. No server, no signup, no installation — everything runs in your browser.

## Features

- 📝 Full Markdown support (headings, tables, lists, bold, italic, links, images, task lists, blockquotes)
- 👁️ Live real-time preview as you type
- 🖨️ PDF download via browser Print API
- 📂 Drag & drop `.md` / `.txt` file import
- 💾 Auto-save to browser localStorage
- 🎨 10+ themes (Colorful, Elegant, Minimalist, Dark, Rose, Ocean, Forest, Sunset, Lavender, Monochrome, Royal, Emerald)
- 🔤 12+ fonts (Inter, Playfair Display, Lora, Merriweather, Raleway, Nunito, DM Sans, etc.)
- 💻 Code syntax highlighting (180+ languages via highlight.js)
- 📊 Mermaid diagrams (flowcharts, sequence diagrams, Gantt charts)
- 🧮 KaTeX math rendering (LaTeX syntax)
- 🌱 PlantUML diagram support
- 🖼️ Drag & drop image embedding
- ✂️ Split view (side-by-side editor + preview)
- 🔍 Find & Replace
- ⌨️ Shortcuts: Ctrl+S (save), Ctrl+F (find), Ctrl+Enter (preview)

## How to Use

**Online:** Go to [shabbeerisgreat.github.io/Pdf-maker](https://shabbeerisgreat.github.io/Pdf-maker/) → type Markdown → Preview → Download PDF

**Offline:** Download `index.html` → double-click to open in browser → done!
