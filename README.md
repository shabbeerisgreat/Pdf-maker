## ✨ What It Does

This is a **browser-based tool that converts Markdown text into beautiful PDF documents**. You type or paste your Markdown on the left side, and it instantly shows you a formatted preview on the right. When you're happy with how it looks, click one button to download it as a PDF. Everything runs in your browser — no server, no signup, no installation needed.

### Core Features
- 📝 **Rich Markdown Rendering** — Full support for headings, tables, lists, bold, italic, links, images, blockquotes, horizontal rules, task lists, and more
- 👁️ **Live Preview** — See your formatted document update in real-time as you type
- 🖨️ **PDF Export** — Generate clean, selectable-text PDFs using the browser's built-in Print API
- 📂 **File Import** — Drag & drop or click to load `.md` / `.txt` files
- 💾 **Auto-Save** — Your work is automatically saved to browser localStorage (never lose your work)

### Themes & Fonts
- 🎨 **10+ Professional Themes** — Colorful, Elegant, Minimalist, Dark, Rose, Ocean, Forest, Sunset, Lavender, Monochrome, Royal, Emerald
- 🔤 **12+ Custom Fonts** — Inter, Playfair Display, Lora, Merriweather, Raleway, Nunito, Source Serif 4, DM Sans, Crimson Pro, Josefin Sans, Libre Baskerville, and more
- 📐 **Page Size Options** — A4, Letter, Legal, A3, A5 with customizable margins
- 📄 **Header & Footer** — Optional document title header and page number footer in PDF
- 📑 **Auto Table of Contents** — Automatically generate a clickable TOC from your headings

### Advanced Features
- 💻 **Code Syntax Highlighting** — Powered by highlight.js, supports 180+ programming languages
- 📊 **Mermaid Diagrams** — Write flowcharts, sequence diagrams, Gantt charts directly in Markdown
- 🌱 **PlantUML Support** — Embed PlantUML diagrams via the online encoder
- 🧮 **KaTeX Math** — Beautiful math rendering using LaTeX syntax (both inline `$...$` and display `$$...$$`)
- 🖼️ **Image Embedding** — Drag & drop images directly into your document
- 😀 **Emoji Picker** — Quick-insert emojis into your Markdown
- ✂️ **Split View** — Side-by-side editing and preview mode
- 🔍 **Find & Replace** — Search and replace text in your Markdown source
- 📊 **Word Frequency Analysis** — See the most-used words in your document
- ⌨️ **Keyboard Shortcuts** — Ctrl+S (save), Ctrl+F (find), Ctrl+Enter (preview)

## ⚡ How to Use

**No installation. No build step. No server. Just open and use.**

### Use Online (Easiest)
1. Go to **[shabbeerisgreat.github.io/Pdf-maker](https://shabbeerisgreat.github.io/Pdf-maker/)**
2. Type or paste your Markdown in the left editor
3. Click **Preview** to see the formatted result
4. Click **Download PDF** to save it as a PDF file

### Use Offline
1. Download `index.html` from this repository
2. Double-click it to open in any browser
3. That's it — everything works offline without internet!

### Use via Terminal
```bash
git clone https://github.com/shabbeerisgreat/Pdf-maker.git
cd Pdf-maker
open index.html    # macOS
xdg-open index.html  # Linux
start index.html     # Windows
```
